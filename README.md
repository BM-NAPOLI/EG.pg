# 📝 تطبيق إدارة المهام (To-Do App)

هذا المشروع هو تطبيق بسيط لإدارة المهام تم تطويره باستخدام *لغة Python* ويعمل داخل *الترمينال (Terminal)*.

يهدف المشروع إلى التدرب على:
- أساسيات لغة Python
- البرمجة كائنية التوجه (OOP)
- التعامل مع القوائم (Arrays / Lists)
- تنظيم الكود بشكل بسيط وواضح

---

## ⚙️ فكرة المشروع

- يتم تمثيل كل مهمة على شكل *كائن (Object)*.
- يتم تخزين جميع المهام داخل *مصفوفة (List)*.
- يمكن للمستخدم التفاعل مع التطبيق عبر الترمينال.

---

## ✨ المميزات

- إضافة مهام جديدة
- عرض جميع المهام
- تحديث حالة المهمة (منجزة / غير منجزة)
- حذف مهمة
- تطبيق خفيف وسهل الاستخدام

---

## 🧱 التقنيات المستخدمة

- Python 3
- Terminal / Command Line
- Object-Oriented Programming (OOP)
